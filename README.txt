BATTLE SETUP — PWA PACKAGE

Contents:
- index.html: Sensitivity Builder app
- manifest.json: installable app metadata
- service-worker.js: basic offline caching
- icons/: 192px and 512px app icons

Important:
1. This package is a Progressive Web App source package, not an APK or AAB.
2. It must be hosted on a public HTTPS website before PWABuilder can package it.
3. Keep the site files together and preserve the folder structure.
4. Test the website on your own phone before attempting store publication.
5. Do not share private passwords, signing keys, or account verification codes.

The app only creates suggested settings and stores user preferences. It does not connect to or modify any game.
